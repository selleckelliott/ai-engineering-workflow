# AI Engineering Workflow

Shared, version-controlled planning protocols, agent skills, orchestration, and Wayfinder tooling for AI-assisted software engineering.

This repository is intentionally project-neutral. Adoption into existing product repositories will be evaluated and planned independently for each project.

## Vendored upstream snapshot

This repository contains a complete vendored subtree of [`mattpocock/skills`](https://github.com/mattpocock/skills) at `upstream/mattpocock-skills`. It is kept as an identifiable, pinned upstream snapshot so its provenance, license, and future updates can be reviewed deliberately. Customization will happen later under a separate, explicitly chosen strategy rather than by changing the imported snapshot during this import.
